# MemberStack

MemberStack is a full-stack membership management platform designed to help organizations manage members, subscriptions, attendance, and payments from a centralized dashboard.

The goal of this project is to build a scalable system that simplifies member administration for organizations such as gyms, clubs, and communities.

## 🚀 Features

### Member Management
- Create, update, and manage member profiles
- Track membership status
- View membership history
- Manage active and expired memberships

### Attendance Tracking
- Record member attendance
- Designed for future QR/NFC-based check-in integration
- Monitor member activity

### Payment Management
- Track membership payments
- Monitor payment status
- Identify expired or upcoming renewals

### Authentication & Authorization
- Secure authentication with JWT
- Protected API routes
- Role-based access control (planned)

### Admin Dashboard
- Centralized overview of members
- Manage organization data
- View important membership metrics
